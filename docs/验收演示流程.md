# 验收演示流程

本文档用于期末验收现场演示。建议按“启动系统 -> 进程管理 -> 内存管理 -> 文件系统 -> 设备与 IPC -> 测试结果”的顺序展示。

## 1. 编译和启动

编译主程序：

```bash
g++ -O2 -std=c++14 -D_DEFAULT_SOURCE \
    os_sim_main.cpp \
    memory/memory.cpp \
    process/program.cpp \
    process/device.cpp \
    process/ipc.cpp \
    filesystem.cpp \
    disk.cpp \
    -o os_simulator \
    -pthread
```

启动系统：

```bash
./os_simulator
```

浏览器访问：

```text
http://127.0.0.1:8080/
```

演示点：

- 系统启动日志。
- 前端状态面板。
- 命令行交互入口。
- 当前调度算法、进程队列、内存位图、文件列表。

## 2. 进程管理演示

创建多个进程：

```text
create P1 8 4096 10
create P2 6 2048 6
create P3 10 8192 15
```

查看队列和 PCB：

```text
ps
queues
pinfo 2
```

切换调度算法：

```text
setsched priority
setsched sjf
setsched fcfs
setsched hrrn
```

阻塞、唤醒、挂起、恢复：

```text
block 2 3 io_wait
queues
wakeup 2
suspend 3
resume 3
```

父子进程和回收：

```text
fork 2
ptree
wait 2
kill 3
pstat
```

验收说明：

- PCB 中包含进程名、状态、优先级、时间片、运行时间、等待时间、阻塞时间等信息。
- 系统能展示运行队列、就绪队列、阻塞队列、挂起队列、结束队列和僵尸队列。
- 支持多种调度算法，满足课程要求的 1 到 2 种以上调度算法。

## 3. 内存管理演示

查看内存统计：

```text
memstat
```

切换页面置换算法：

```text
setmem FIFO
setmem LRU
setmem CLOCK
```

模拟地址访问和地址转换：

```text
access 2 0x1000
access 2 0x2000
translate 2 0x1000
memstat
```

共享内存：

```text
shm 2 3 1
```

动态调整进程内存：

```text
resize 2 4096
resize 2 -4096
```

验收说明：

- 内存模块采用分页式虚拟内存。
- 访问未装入页面时会触发缺页中断。
- 支持 FIFO、LRU、CLOCK 三种页面置换策略。
- `os_memory_config.txt` 可配置物理页数和默认策略。

## 4. 文件系统演示

创建目录和文件：

```text
pwd
ls
mkdir demo
cd demo
touch note.txt
write note.txt hello_os
cat note.txt
```

偏移读写：

```text
read_at note.txt 0 5
write_at note.txt 6 simulator
cat note.txt
```

属性和 inode：

```text
chmod note.txt ro
stat note.txt
chmod note.txt rw
```

目录树、重命名、复制、搜索：

```text
rename note.txt report.txt
cp report.txt backup.txt
grep hello report.txt
tree
```

Vim 风格编辑：

```text
vim report.txt
```

验收说明：

- 文件系统支持文件创建、删除、读写、属性修改。
- 支持目录创建、删除、切换和树形展示。
- 文件内容通过虚拟磁盘 `vdisk.bin` 持久化保存。
- inode 中记录文件类型、大小、权限和数据块位置。

## 5. 设备管理和 IPC 演示

设备申请与释放：

```text
io 2 0
io 3 0
release 2
```

信号量：

```text
sem_create mutex 1
P mutex 2
P mutex 3
V mutex
```

消息通信：

```text
msg_send 2 3 hello_from_P2
msg_read 3
```

验收说明：

- 设备模块维护设备占用状态和等待队列。
- 银行家算法用于资源安全性检查。
- IPC 模块支持信号量和进程消息邮箱。

## 6. 测试展示

文件系统测试：

```bash
g++ -O2 -std=c++11 test_fs.cpp filesystem.cpp disk.cpp -o run_fs_test -pthread
./run_fs_test
```

磁盘和内存测试：

```bash
g++ -O2 -std=c++11 \
    disk.cpp \
    memory/memory.cpp \
    test_disk_memory.cpp \
    -o os_sim_test_disk_memory \
    -pthread
./os_sim_test_disk_memory
```

压力测试：

```bash
python3 test_os_pressure.py
```

验收说明：

- `run_fs_test` 验证目录、文件读写、权限、重命名、大文件跨块分配和清理。
- `os_sim_test_disk_memory` 验证虚拟内存、缺页中断、页面装入和磁盘 swap 相关能力。
- `test_os_pressure.py` 通过 HTTP 命令并发创建进程和申请设备，用于观察队列和死锁风险。
