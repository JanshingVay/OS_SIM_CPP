# 测试用例

本文档汇总期末验收建议执行的测试用例。测试分为模块测试和整体集成测试两类，既可以通过脚本自动执行，也可以在前端命令行中手动演示。

## 一键测试

在类 Unix、Cygwin 或 Git Bash 环境中执行：

```bash
bash run_all_tests.sh
```

该脚本会依次完成：

- 文件系统与磁盘测试。
- 磁盘与内存测试。
- 进程、设备、IPC 模块测试。
- 主程序编译。
- HTTP API 整体集成测试。

## 整体集成测试用例

整体测试由 `test_api_integration.py` 执行，需要主程序运行在 `http://127.0.0.1:8080`。`run_all_tests.sh` 会自动编译并启动测试用主程序。

| 编号 | 测试链路 | 测试内容 | 预期结果 |
| --- | --- | --- | --- |
| I01 | 启动链路 | 调用 `/api/boot` | 返回 success，系统 booted 为 true |
| I02 | 进程 + 前端状态 | 通过 `/api/command` 创建两个进程 | `/api/status` 可查询到新进程 |
| I03 | 调度 + 状态 | 执行 `setsched hrrn` | 当前调度算法变为 HRRN |
| I04 | 进程队列 | 执行 `block` 和 `wakeup` | 进程进入并离开阻塞队列 |
| I05 | 挂起队列 | 执行 `suspend` 和 `resume` | 进程进入并离开挂起队列 |
| I06 | 内存 | 执行 `setmem LRU`、`access`、`translate` | 页面置换策略更新，内存访问次数增加 |
| I07 | 文件系统 | 创建目录和文件，写入并读取 | 读回内容包含写入字符串 |
| I08 | 文件属性 | 执行 `chmod ro` 并查询 `/api/file/<name>` | readonly 字段为 true |
| I09 | IPC | 执行信号量 P/V、消息发送和读取 | 消息内容可读回 |
| I10 | 设备 | 执行 `io` 和 `release` | 设备状态可通过 `/api/status` 查询 |

## 手动验收命令

如果不运行自动脚本，也可以在前端命令行中按顺序输入：

```text
create T1 8 4096 10
create T2 6 4096 6
setsched hrrn
queues
block 3 2 test_block
wakeup 3
suspend 4
resume 4
setmem LRU
access 3 0x1000
translate 3 0x1000
mkdir demo_test
cd demo_test
touch a.txt
write a.txt hello_os
cat a.txt
chmod a.txt ro
stat a.txt
chmod a.txt rw
cd ..
sem_create mutex_test 1
P mutex_test 3
V mutex_test
msg_send 3 4 hello_ipc
msg_read 4
io 3 0
release 3
```

验收时建议配合前端状态面板观察进程队列、内存统计、文件列表、设备状态和 IPC 状态变化。
