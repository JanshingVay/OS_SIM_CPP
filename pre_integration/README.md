# pre_integration 模块说明

本目录保留各成员在集成前后的模块、前端快照和测试脚本，便于第 11 周验收时按成员分别演示。

## 模块目录

- `01_houbowen_filesystem_shell_vim_frontend`：文件系统、Shell、Vim 与前端快照。
- `02_weijianxing_disk`：虚拟磁盘与块管理。
- `03_cuijingzhe_memory_frontend`：内存管理、MMU 与前端快照。
- `04_xugeshan_process_ai_mmu`：进程管理、MMU、AI/语音/前端接口快照。
- `05_yanghaozhe_frontend_ipc_device`：设备管理、IPC 与前端。

## 运行方式

Windows 下可优先运行各模块目录内的 `RUN_INTERACTIVE_DEMO_WINDOWS.bat` 或 `RUN_MODULE_TESTS_WINDOWS.bat`。
根目录 `RUN_INTERACTIVE_DEMO_MENU_WINDOWS.bat` 可作为模块演示入口菜单。
